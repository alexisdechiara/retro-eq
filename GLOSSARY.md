# Retro EQ

Le vocabulaire du produit : comment on compare deux réglages d'égaliseur à l'oreille, et ce qu'on garde du résultat.

## Langage

### Comparer

**Passage** :
Une période d'écoute continue pendant laquelle une seule des deux versions comparées est active.
_À éviter_ : tour, écoute, séquence

**Duel** :
La comparaison de deux versions, A et B, faite de 3 passages de chacune et close par une réponse.
_À éviter_ : comparaison, manche, round, essai

**Duel de contrôle** :
Un duel dont les deux versions sont identiques, glissé dans un test pour mesurer la part de hasard dans les réponses.
_À éviter_ : duel témoin, duel piège

**Réponse** :
Le choix donné à la fin d'un duel : A, Pareil ou B.
_À éviter_ : vote, avis, résultat

**Test** :
Une série de duels qui part d'une référence et aboutit à une nouvelle version d'un profil.
_À éviter_ : session, parcours, campagne

**Référence** :
La version active avant le test, celle qu'on retrouve toujours quand le test s'arrête, quelle qu'en soit la raison.
_À éviter_ : preset d'origine, base, original

**Variante** :
Une version candidate fabriquée à partir de la référence pour lui être opposée dans un duel.
_À éviter_ : candidat, proposition, mutation

**Confiance** :
Le niveau de certitude d'un résultat, d'après le risque qu'il soit dû au hasard : Indice, Probable ou Sûr.
_À éviter_ : score, fiabilité, certitude

### Garder

**Profil** :
Un réglage d'égaliseur nommé que l'utilisateur garde et peut activer.
_À éviter_ : preset (pour ce qui est gardé dans Retro EQ), configuration, réglage

**Version** :
Un état figé d'un profil. Chaque test en crée une nouvelle ; aucune n'est supprimée.
_À éviter_ : révision, sauvegarde, archive

### Faire sonner

**Sortie audio** :
Un périphérique de lecture vu par Windows, sur lequel le son peut être égalisé.
_À éviter_ : périphérique, device, endpoint, casque (quand on parle de la sortie)

**Moteur** :
Ce qui applique réellement une version au son d'une sortie audio.
_À éviter_ : backend, driver, pilote

## Ambiguïtés à lever

- « Version » désigne à la fois un état d'un profil et, dans « version A » et « version B », les deux côtés d'un duel. À trancher : garder le même mot, ou nommer autrement les deux côtés d'un duel.
- « Preset » revient dans `PRODUCT.md` (presets de départ, presets Peace) à côté de « profil ». À trancher : un preset est-il un profil comme un autre, ou un point de départ en lecture seule ?
