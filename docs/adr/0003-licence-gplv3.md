# Retro EQ sous GPLv3

Slint est gratuit pour un logiciel libre sous GPLv3, payant ou à contraintes sinon ; on publie donc Retro EQ sous GPLv3, code source public. Cela ferme la porte à une version propriétaire tant que Slint est là, et limite les dépendances aux licences compatibles : MIT, Apache 2.0, BSD, GPL. Toute dépendance sous une autre licence est signalée avant d'être ajoutée.
