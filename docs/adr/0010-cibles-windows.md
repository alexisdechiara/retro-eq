# Cibles : Windows 10 22H2 et Windows 11, x64 seulement

Retro EQ vise Windows 10 22H2 et Windows 11, en x64. ARM64 est laissé de côté : aucun matériel pour l'essayer, et le moteur audio doit exister dans la même architecture que le service audio de Windows. Mac et Linux ne sont pas prévus ; le code pur (`retro-dsp`, `retro-core`) y compile quand même, ce qui sert aux tests.
